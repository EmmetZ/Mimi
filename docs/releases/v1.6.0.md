## English

- Reorganized desktop settings: audio and languages, service configurations, and saved sessions are easier to find. Configuration lists, icons and page navigation are clearer and more consistent.
- Added Alibaba simultaneous translation on desktop and Android, alongside ASR + MT. Existing configurations keep their selected mode.
- Android can now save multiple configurations for the same service, with separate credentials and text translators. Existing configurations migrate automatically.
- Fixed lost previews, repeated captions and late results disrupting newer sentences with Tencent, Baidu and Volcano.
- Reduced translation waits, including unnecessary thinking time on supported text translation services.
- Windows now removes old updater installers after launching the installed version.

Update through Mimi’s update settings or download the installer. Live drafts may still change during recognition. macOS builds are not Apple-notarized.

Contributors: @yuxino, @wangmian0.

## 中文

- 重新整理桌面设置，声音与语言、服务配置、保存与导出更好找；统一配置列表、图标和页面跳转。
- 桌面和安卓的阿里云均支持同声传译，也可选择 ASR + MT。现有配置保持原来的模式。
- 安卓支持为同一家服务添加多套配置，分别保存凭证和文字翻译服务；旧配置自动迁移。
- 修复腾讯、百度、火山引擎部分字幕预览丢失、重复，以及迟到结果打乱后续字幕的问题。
- 缩短部分翻译等待，关闭支持的文字翻译服务中不必要的思考过程。
- Windows 新版启动后自动清理旧的升级安装包。

可在 Mimi 更新设置中升级，或下载安装包。识别过程中的临时字幕仍可能修改。macOS 安装包尚未经过 Apple 公证。
